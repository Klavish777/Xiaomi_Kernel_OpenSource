# 🎬 Genius Video AI

Бесплатный ИИ-генератор видео: **опишите идею, получите готовый ролик.** API-ключи не нужны.

```
идея ─► 🧠 ИИ-режиссёр (сценарий) ─► 🎨 ИИ-художник (кадры) ─► 🎬 монтаж (локально) ─► MP4
```

## Возможности

- **Раскадровка от ИИ.** По идее генерируются заголовок, сцены, субтитры на языке пользователя и подробные промпты на английском.
- **Кадры от ИИ.** Модель Flux через [Pollinations.ai](https://pollinations.ai), стили на выбор: кино, фото, аниме, 3D-мульт, акварель, киберпанк, фэнтези, пиксель-арт.
- **Режим «Из моих фото»:** загружаете свои картинки, получаете клип.
- **Кинематографичный монтаж:**
  - плавное движение камеры (эффект Кена Бёрнса: наезд, отъезд, панорамы);
  - переходы: растворение, через чёрный, зум, сдвиг, шторка;
  - цветокоррекция: кино, сочный, тёплый, холодный, винтаж с зерном, нуар;
  - анимированные субтитры и заголовок.
- **Саундтрек.** Встроенный синтезатор с пятью настроениями или ваш аудиофайл.
- **Форматы:** 16:9 (YouTube), 9:16 (Shorts/TikTok/Reels), 1:1, 4:5.
- **Редактор раскадровки:** правка подписей и промптов, перерисовка кадра, перестановка, удаление и замена сцен.
- **Галерея** готовых видео.
- **Работа без интернета.** Если сервисы ИИ недоступны, включается шаблонный сценарий и встроенный процедурный художник, так что видео получится всегда.

## Запуск

```bash
./run.sh            # создаст .venv, поставит зависимости, запустит сервер на :8000
# или
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000. Системный ffmpeg не нужен: он подтягивается пакетом `imageio-ffmpeg`.

## Как устроено

| Часть | Файл | Что делает |
| --- | --- | --- |
| Интерфейс | `static/` | Vanilla JS. Сценарий и кадры запрашиваются у Pollinations прямо из браузера (CORS разрешён) |
| API | `app/main.py` | FastAPI: `/api/render`, `/api/jobs/{id}`, `/api/videos`, `/api/procedural` |
| Рендер | `app/render.py` | Кадры собираются в Pillow/NumPy с субпиксельной камерой и передаются в ffmpeg (H.264 + AAC) |
| Музыка | `app/music.py` | Процедурный синтез: пэды, бас, арпеджио, задержка |
| Офлайн-художник | `app/procedural.py` | Рисует сцену по ключевым словам промпта |

Рендеры выполняются по очереди, по одному. Ролик из 5 сцен в 720p собирается за 10–20 секунд на 2 ядрах CPU.
